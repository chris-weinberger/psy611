Question 5: Population and sample variance

Create a variable called X containing the following values:

4, 2, 5, 3, 2, 4, 5, 1, 1, 5

# Create X
X <- c(4, 2, 5, 3, 2, 4, 5, 1, 1, 5)

Imagine first that these 10 observations constitute the entire population.

  1. Calculate the mean of X.
  2. Calculate the sum of squared deviations from the mean.
  3. Divide this quantity by the population size, N, to calculate the population variance.
# Calculate the population variance
N <- 10
mean_x <- mean(X)

sum_sqr_dev <- sum((X-mean_x)**2)

var_x <- sum_sqr_dev / N

Now imagine instead that these 10 observations constitute a sample from a larger population.

Use R’s var() function to calculate the sample variance.

# Calculate the sample variance
